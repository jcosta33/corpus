# Glossary

| Term | Meaning |
| --- | --- |
| **Intent** | What the change must make true. At minimum weight, one inline sentence. |
| **Scaffold** | Structure pulled in only when work earns it: a spec, an audit, research, or a campaign. |
| **Spec** | Working structured intent: intent and verifiable requirements, plus only the optional sections that carry information. |
| **Requirement / AC** | One condition, one observable obligation with exactly one binding word, and one verification method, under a stable spec-local ID. |
| **Baseline, waves, cutover** | The spec sections for structural change: proven current state, ordered green steps with rollback points, and the switch-over conditions. |
| **Audit** | An evidence-backed map of present state, optionally graded for risk; no prescriptions. |
| **Research** | Evidence for one decision-informing question; no decision. |
| **Campaign** | A restartable multi-pull-request goal contract. Mutable progress stays in one project-native ledger. |
| **Ledger** | The project-native issue, epic, or equivalent that owns a campaign's work items and status. |
| **Worktree lane** | One worktree with one active branch and one implementation owner. |
| **Control strength** | Advisory, deterministic local, or isolated authority: how strongly a delivery rule actually binds. |
| **Independent review** | A non-implementer judges the result on the native pull request. No Corpus review file. |
| **Evidence** | Directly inspectable output, a CI run, or a named manual observation tied to a claim. |
| **Evidence receipt** | An untyped sidecar holding raw command records under stable `E-NNN` anchors. |
| **Run note** | An untyped sidecar for execution or round detail too large for its governing artifact. |
| **Finding** | A lesson candidate. It is not an artifact type. |
| **Native memory** | A harness-provided durable memory surface, used only when supported. |
| **Artifact disposition** | The human close choice for a complete artifact set: Delete, Leave, or Promote. |
| **Universal methods** | Skills that write no artifact (`bulletproof`, `debloat`, `dissect`, `drill`, `panel`, `revolver`, `settle`); they install from `jcosta33/skills`. |

Working artifacts direct live work. After close, code, tests, maintained project records, and
supported native memory carry durable truth.
