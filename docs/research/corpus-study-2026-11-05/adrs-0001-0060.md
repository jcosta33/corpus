**Citation convention.** `NNNN:L` means `docs/adrs/NNNN-*.md` line L. `README:L` means `docs/adrs/README.md` line L. Git hashes come from `git log` in the repo. Ledger row line = ADR number + 34 (for example 0050 → `README:84`).

**Status format.**
- 0001–0026 have no frontmatter. Status is a `## Status` heading at line 3, with the value at line 5.
- 0027–0056 carry YAML frontmatter (`type/id/status/created/updated/supersedes/superseded_by`) **and** a separate `## Status` section near the end. The two can disagree (see §2).
- 0057–0060 carry short frontmatter (`id: adr-00NN`, no `supersedes`/`superseded_by` keys) plus `## Status`.

For 0001–0026 the "created" column below is the git first-commit date, since the files carry no date.
